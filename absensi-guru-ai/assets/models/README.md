# Instruksi Model face-api.js

Letakkan seluruh file model face-api.js di folder ini agar dapat diakses pada path:

- `./assets/models/tiny_face_detector_model-weights_manifest.json`
- `./assets/models/face_landmark_68_model-weights_manifest.json`
- `./assets/models/face_recognition_model-weights_manifest.json`

Unduh model resmi face-api.js dari repository berikut:
https://github.com/justadudewhohacks/face-api.js/tree/master/weights

Pastikan seluruh file `.json` dan file shard `.bin` ikut disalin.
